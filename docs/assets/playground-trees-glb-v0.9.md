# 操场树木 GLB v0.9：根部裸土圈

三种操场树的树干底部均增加 `Root_Soil_Ring`：

- 使用轻微隆起的双层低面数网格，中央与树干相交，外圈落到地面。
- 外边缘加入不规则起伏，避免规则圆盘外观。
- 使用单一手绘棕色哑光材质，不增加泥土贴图。
- 每个裸土圈只有 36 个面。
- 半径：木麻黄 0.82 米、羊蹄甲 0.76 米、樟树 0.88 米。

大榕树和三种树木原有的整树唯一 UV 树皮实现均未改变。
