# 二号教学楼合金窗 GLB v0.1

## 文件

- Blender 源文件：`assets/source/blender/b2-window-v01.blend`
- 运行时 GLB：`public/assets/models/building-2/b2-classroom-window-alloy-v01.glb`

## 工作尺寸

- 整体宽：`1.50 m`
- 整体高：`1.55 m`
- 最大结构深度：约 `0.11 m`
- 顶部气窗区：约 `0.35 m`
- 下部主窗区：约 `1.20 m`

这些尺寸用于匹配当前二号教学楼窗洞，不代表原建筑测绘精度。

## 结构与交互

- 银灰色细合金外框、中央竖梃和上下分隔梁。
- 下部左右两扇主窗均分成上下两块玻璃，绕各自外侧竖轴向室外打开，建议开角 `60°`。
- 上部左右气窗绕穿过窗扇中心的水平轴翻转，建议开角 `24°`。
- 室内侧防盗网固定在窗框根节点，不跟随任何窗扇运动；包含四根竖杆和三道浅波浪横杆。
- GLB 根节点保存米制单位、朝向、尺寸和结构说明；四个活动 Pivot 保存轴向、建议角度和向外旋转符号，可供 Three.js 点击开合逻辑直接读取。

## 验证

- 导出文件约 `148 KB`，包含 `122` 个节点、`116` 个网格和 `3` 个材质。
- 已在 Blender 中统一重算法线。
- 已检查四个活动 Pivot、固定防盗网父子层级、透明玻璃材质和 GLB extras。

## v0.2 UV 材质补全（2026-08-15）

- 全部 `116` 个原网格均已补面向 UV；铝框、防盗网和玻璃改用内嵌 Base Color 与 Roughness 贴图。
- 铝框使用细微拉丝与边缘氧化灰度，保持偏哑光；防盗网使用深色旧铁，并只加入少量低饱和锈斑。
- 玻璃改为轻雾化蓝灰透明材质，降低纯蓝塑料感；金属边缘加入约 `1.4 mm` 小圆角。
- GLB 回读尺寸仍为 `1.50 × 0.111 × 1.55 m`，四个活动 Pivot 和固定防盗网层级均完整保留。

## 场景接入

- 二号教学楼三层共放置 `72` 樘：正面每层 `8` 樘，共 `24` 樘；背面每层 `16` 樘，共 `48` 樘。
- 正面实例保持模型原朝向，外开方向指向走廊；背面实例绕 Y 轴旋转 `180°`，外开方向指向北侧室外。
- 两种朝向的防盗网均位于教室内侧，且开合前后保持固定。
- 主窗和顶部气窗均已接入鼠标点击开合，运行时真实点击分别验证了 `60°` 与 `24°` 的目标角度。

## v0.1 闭合贴合修正

- 草图中的粗线仅用于区分窗扇、固定框和中梃，不代表真实结构留缝。
- 初版曾在主窗中梃一侧保留约 `21 mm`、上下各约 `20 mm` 的可见间距，顶部气窗四周也保留约 `5 mm`，现已取消。
- 主窗扇改为约 `0.701 × 1.149 m`，顶部气窗改为约 `0.701 × 0.301 m`；闭合边缘略微压入固定框和中梃后方 `1–3 mm`，不再出现透空带，只保留细金属接缝。
- 调整后重新导出 GLB，场景中 `72` 樘实例加载正常；主窗 `60°`、气窗 `24°` 的开合运动及固定防盗网均通过复测。
