# 操场树木 GLB 资产 v0.4

日期：2026-08-15  
状态：调整羊蹄甲、樟树末梢树冠结构并缩小樟树主干；场景尚未接入。

## 修改内容

- 木麻黄恢复并保持已确认的 v03 叶簇数量、枝向和斜向上生长方式。
- 羊蹄甲和樟树的叶簇位置限制在每条末级细枝最外侧18%及最终枝尖。
- 叶簇卡片不再以枝端为中心平均向内、向外展开；根部只少量压进枝端，约80%的叶团长度继续沿父枝向树冠外侧伸展。
- 同一末级枝上的两个终端叶团共用一致的由内向外生长轴，用于补足树冠，但不在整条枝干周围生成叶片。
- 樟树主干基部半径由0.48 m缩小到0.38 m，直径约缩小21%；上段树干同步按比例收细。树高和树冠尺度不变。
- v02 的大型复合叶簇、小叶尺度、六种图块、Alpha Mask、双面与 unlit 材质继续沿用。
