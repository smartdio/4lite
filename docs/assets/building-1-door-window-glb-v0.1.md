## 层级与开合

- 每个门资产有一个门扇铰链 Pivot；Pivot 轴线穿过教室侧铰链圆柱中心。三枚铰链固定在门框根节点，门扇开合时不随门板移动；固定亮窗同样不旋转。
- 每个窗资产有六个独立 Pivot：四个气窗上沿 Pivot、两个中窗外侧边 Pivot。
- 窗安装底标高为 `0.70 m`，成品高 `1.85 m`，安装后顶部标高 `2.55 m`，与门顶齐平。
- 上、下气窗已按复核意见加高，净高各约 `0.35 m`；中间主窗净高约 `0.85 m`。
- 门的推荐展示开启角约 `85°`。
- 气窗推荐开启约 `20°`，中间平开窗推荐开启约 `60°`。
- Pivot 自定义属性记录 Blender 坐标下的开合方向；导入 Three.js 后应按节点名绑定，不以整个 GLB 根节点旋转代替。
- 门资产的局部 `-Z` 定义为教室内侧；走廊门、北墙门和两翼门只通过根节点旋转适配墙面，开门目标始终保持局部 `-Z`，不单独反转开合符号。

## 材质插槽

- `wood_base`：军绿色木框、竖档和横档。
- `wood_panel`：略浅的军绿色内凹门芯板。
- `glass_base`：玻璃工作材质。
- `metal_dark`：门铰链工作材质。

上述颜色只用于模型识别和首轮风格检查，后续可由材质线替换；替换时不得合并或改名活动 Pivot。

### v0.2 UV 材质补全（2026-08-15）

- 四个资产已改用 1024 px UV Base Color 与 Roughness 贴图，贴图内嵌于 GLB；不再依赖识别用纯色。
- 军绿色旧漆木框在结构交界处压暗，边缘以不连续小面积掉漆露出褐色木底；门芯板使用独立贴图，保留很轻的三拼木板缝。
- 玻璃改为低饱和蓝灰旧玻璃，带轻微雾化变化；铰链使用高粗糙度深色旧铁。
- 所有盒状部件重新制作面向 UV，使掉漆沿真实边缘分布，门板拼缝仅稳定落在门芯主面。
- 加入约 `2.2 mm` 的非破坏小圆角以承接边缘高光；尺寸、对象名、父子层级和活动 Pivot 均保持不变。

- 一号楼、二号楼与旧教室复用门窗共登记 `122` 个放置位置；相同 GLB 的各子网格按节点实例化，当前形成 `120` 个实例绘制对象。
