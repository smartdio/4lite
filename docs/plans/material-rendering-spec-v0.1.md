# 记忆中的学校｜材质与风格渲染规范 v0.1

制定日期：2026-08-10  
适用范围：Three.js 建筑主体、地面、设施与后续 GLB 资产的视觉表现  
上游依据：`art-direction-v0.1.md`、`handoff.md` 与当前 `src/main.js`  
状态：首轮实施规范；候选数值须经立面样板确认后才能升为正式值

首轮实施记录：[`old-classroom-material-sample-v0.1.md`](old-classroom-material-sample-v0.1.md)

## 1. 目标与边界

本项目的画面目标是原创的怀旧手绘动画背景感：盛夏接近正午，阳光明亮，阴影通透，建筑和旧设施以清楚的赛璐璐主色块表现，局部色差和阴影过渡带有柔和水彩感。

本规范中的视觉修改不得改变已经确认的：

- 校园总平面、建筑中心、楼层高度、墙厚和教室尺寸；
- 门窗洞口、走廊、楼梯、围墙、高台和设施坐标；
- 独立行走碰撞体和通行净宽；
- 一号楼花格栏杆的“实体上下梁＋透明贴图花格”方案；
- 厕所入口只以墙面贴图表达、不切实体门洞的结论。

材质、光照、描边和后期均为可独立关闭的表现层。关闭描边与后期后，材质和基础光照仍必须形成完整、可读的画面。

## 2. 视觉语言

### 2.1 必须保留

- 清楚的大色块和稳定的明度层级；
- 暖而不黄的日照面、偏蓝绿但不死黑的阴影面；
- 可辨认的门洞、台阶、栏杆、檐口和墙体转折；
- 低频、方向明确、数量克制的旧化；
- 米制空间中的真实光照方向和阴影关系；
- 材质之间依靠颜色、粗糙度和轮廓区分，而不是依靠高频细节堆叠。

### 2.2 禁止使用

- 照片污渍直接平铺、扫描材质或照片级 PBR；
- 水彩纸纹、纸纤维、颜料颗粒及全屏噪点；
- 强烈法线、湿亮高光、镜面黑瓦和塑料感墙面；
- 统一覆盖全画面的橙黄色“复古滤镜”；
- 大量泛光、镜头光晕、明显暗角、景深模糊和电影黑边；
- 为制造风格而模糊空间边界或改变模型比例；
- 直接复制现有动画作品的具体画面、配色或专有设计。

## 3. 色彩与色彩管理

### 3.1 渲染色彩空间

- 渲染器输出保持 `THREE.SRGBColorSpace`。
- 基础色、颜色遮罩中供人直接观看的 RGB 贴图必须标记为 sRGB。
- 粗糙度、法线、AO、透明度和其他数据贴图必须保持线性数据，不设置 sRGB。
- 色彩计算在线性空间完成；禁止在贴图中预烘焙整场景色调映射。
- 继续使用 ACES Filmic 作为 v0.1 基线，曝光以 `1.00–1.10` 为候选范围，当前 `1.08` 可作为起点。
- 所有视觉验收使用同一浏览器、同一曝光和同一时间段，避免用显示条件差异误判材质。

### 3.2 场景基准色板

以下为起始色域，不是要求所有表面使用单一纯色：

| 角色 | 候选色域 | 使用说明 |
| --- | --- | --- |
| 天空／远雾 | `#B9DEEC` 附近 | 高明度青蓝，远雾与天空同色相 |
| 日光 | `#FFF1C9` 附近 | 奶油浅金，不偏橙 |
| 阴影倾向 | 蓝绿灰 | 保持结构可读，禁止纯黑 |
| 一号楼浅墙 | `#E7DDB9` 附近 | 暖灰米白，允许轻微褪色 |
| 二号楼黄墙 | `#D7AB5D` 附近 | 降低饱和度，避免玩具黄 |
| 旧石灰墙 | `#DEDCD0–#E7E3D5` | 中性暖灰白，墙脚稍冷暗，不呈奶油黄 |
| 露砖 | `#9A6449` 附近 | 柔和旧砖红，不鲜艳 |
| 旧木 | `#765235` 附近 | 偏暖深褐，亮面克制 |
| 铁件 | `#344E47` 附近 | 偏青深灰，避免纯黑 |
| 黑瓦 | `#4B504B` 附近 | 暖黑灰，受光面必须有层次 |
| 青苔 | `#68794F` 附近 | 低饱和橄榄绿，局部出现 |
| 夏季植物 | `#427344–#6D9950` | 亮部黄绿、暗部青绿 |

任何新材质应先在这套综合色域中寻找位置；只有历史资料明确要求时才新增明显脱离色板的颜色。

## 4. 材质系统架构

### 4.1 分层原则

每种建筑材质由以下层次组成，前一层必须先成立：

1. **主色层**：决定材质的大色块、整体明度和年代色彩。
2. **低频变化层**：柔和的手绘色差、褪色和不均匀粉刷感。
3. **叙事旧化层**：墙脚潮痕、少量露砖、门边磨损、青苔等有位置原因的变化。
4. **受光层**：基础环境光、主光和可读阴影。
5. **风格辅助层**：简练明暗分层、结构描边和非常轻的综合色彩统一。

不得用第 5 层掩盖前四层的问题。

### 4.2 Three.js 材质基线

- 第一版继续使用 `MeshStandardMaterial` 作为共同受光基线，`metalness` 默认为 `0`。
- 铁窗等涂漆铁件仍按非金属涂层处理；除旗杆裸露金属候选外，不启用明显金属反射。
- 建筑常规粗糙度保持 `0.82–1.00`；旧木可用 `0.78–0.92`；旧铁可用 `0.72–0.90`。
- 法线只用于轻微打散大平面高光，不承担主要造型。墙面法线强度不超过约 `0.15`，水泥不超过约 `0.20`，瓦片可在近景验证后提高到约 `0.30`。
- 不使用视差、置换或会改变已确认轮廓的材质效果。
- 同一材质族共享贴图和基础参数，通过颜色偏移、局部遮罩或实例参数产生变体，禁止为每段墙复制一整套大贴图。

### 4.3 建议代码层级

后续实现应将当前 `src/main.js` 中的纯色 `mat` 表逐步替换为独立材质模块，但空间参数继续只来自 `campus-config.js`。

建议结构：

```text
src/materials/
  material-library.js       材质族、纹理缓存与统一参数
  texture-projection.js     米制 UV／世界投射辅助
  stylized-lighting.js      可关闭的明暗分层扩展
  rendering-style.js        光照、雾、曝光、描边与调试开关
public/assets/textures/
  shared/
  limewash/
  concrete/
  brick/
  wood/
  painted-steel/
  roof-tile/
  moss/
```

所有纹理必须由统一缓存加载；不得在每个模型实例中重复创建 `TextureLoader` 和同源纹理。

## 5. 贴图制作规范

### 5.1 文件与命名

材质标识使用小写英文与连字符：

```text
<family>-<variant>-<channel>-v<major>.<ext>
```

示例：

```text
limewash-old-warm-basecolor-v1.webp
limewash-old-warm-roughness-v1.webp
limewash-old-warm-normal-v1.webp
limewash-old-warm-mask-v1.png
```

通道名统一使用：`basecolor`、`roughness`、`normal`、`ao`、`opacity`、`mask`。源文件和导出文件分开保存；运行时目录只放经过压缩的交付纹理。

### 5.2 分辨率与格式

- 通用可平铺基础色：默认 `1024 × 1024`；只有近距离差异确实可见时才使用 `2048 × 2048`。
- 粗糙度、AO 和低强度法线：默认 `512 × 512` 或 `1024 × 1024`。
- 独特局部遮罩：按物体占屏比例选择 `512–1024`，不为远景物体使用 2K 独占贴图。
- 基础色优先使用高质量 WebP；需要精确透明边缘或无损遮罩时使用 PNG。
- 法线和数据贴图在压缩前检查色阶，避免有损压缩产生块状伪影。
- 纹理尺寸使用 2 的幂，启用 mipmap；斜视地面和长墙使用设备允许的各向异性过滤，但统一设上限，避免无条件取满。

第一轮样板的新增运行时纹理预算建议不超过 `8 MB`，经样板确认后再制定全场预算。

### 5.3 米制纹理密度

不以每个几何体的默认 `0–1 UV` 拉伸整张纹理。基础纹理采用稳定的米制尺度：

| 材质族 | 推荐单次重复覆盖范围 |
| --- | --- |
| 石灰墙／粉刷墙 | `2.5–4.0 m` |
| 水泥地面 | `3.0–5.0 m` |
| 旧砖 | 依据砖的真实工作尺寸排布，首版约 `0.24 × 0.06 m` 单砖 |
| 木材低频色差 | `0.8–1.5 m`，纹理方向跟随构件长向 |
| 黑瓦整体色差 | `2.0–3.0 m`；瓦片节奏另行控制 |
| 青苔／潮痕遮罩 | `2.0–4.0 m`，不得形成明显重复斑点 |

大型参数化墙体、地面、高台和围墙优先采用世界坐标或统一局部米制投射，使不同墙段保持相同纹理密度。投射接缝应落在建筑转角、柱后或材质自然分界处。

GLB 门窗和家具使用正式 UV；其 texel 密度应与相同观看距离的建筑材质接近。禁止通过缩放模型修正纹理密度。

### 5.4 手绘变化规则

- 单张基础色贴图的明度变化以低频、柔和为主，避免明显云噪声。
- 水彩感表现为少量不规则色边、宽而软的色差和局部半透明叠色感，不表现纸张表面。
- 大面积墙面基础变化的明度振幅建议控制在约 `±4%–7%`。
- 旧化遮罩必须能解释其来源：墙脚受潮、檐下积灰、门把附近磨损、裂损处露砖。
- 同一立面最多设置一至两个视觉重点旧化区，其余保持安静。
- 露砖区域边缘需有石灰层厚度和不规则缺口感，但不得用密集法线模拟碎裂废墟。
- 青苔主要出现在墙脚、排水慢处、土坡边、高台边缘和厕所旧墙；二层高处不得无原因大面积出现。

## 6. 可复用材质族

### 6.1 `limewash-clean-warm`：较完整暖白石灰墙

用于一号楼等维护相对较好的墙面。

- 暖灰米白主色；轻微纵向粉刷色差；
- 基础粗糙度 `0.92–1.00`；
- 旧化仅在墙脚、窗台下和檐下少量出现；
- 不出现大面积露砖。

### 6.2 `paint-faded-ochre`：褪色黄墙

用于二号楼当前黄色墙体方向。

- 降低纯色黄的饱和度，受光面偏浅暖黄，阴影面转为灰橄榄；
- 柱、梁和墙面可使用同族不同明度变体，避免结构融成一片；
- 不加入现代亮乳胶漆的平滑高光。

### 6.3 `limewash-old-exposed-brick`：严重老化石灰墙

用于旧教室和厕所，并允许不同旧化等级。

- 暖灰旧白为主体；墙脚更冷、更暗；
- 局部露出柔和旧砖红，露砖面积先以小于可见墙面的 `12%` 为候选上限；
- 旧教室强调剥落和年代感，厕所允许更重青苔，但都不能成为废墟；
- 采用基础平铺层＋独特局部遮罩，避免每面墙重复同一块剥落图案。

### 6.4 `concrete-aged-light`：旧浅色水泥

用于走廊、台阶、操场硬地、楼板边和旗台。

- 灰白或浅暖灰主色，低频色差大于细颗粒；
- 地面可有方向柔和的磨耗区，但不画密集裂缝；
- 台阶踏面比立面略暗，帮助行走识别；
- 粗糙度 `0.90–1.00`，法线极弱。

### 6.5 `wood-painted-aged`：旧木门窗

- 以整体褐色或旧漆大色块为主，木纹只作近景次要信息；
- 木纹必须顺构件长向，不跨门框方向错误；
- 门下沿、把手附近和常接触边缘允许轻微褪色；
- 禁止清漆家具般的强高光和高对比年轮纹。

### 6.6 `painted-steel-dark-green`：旧铁窗与铁件

- 深青灰或暗绿灰涂层，视作高粗糙度非金属；
- 锈色只在接缝、下沿和破损点少量出现；
- 轮廓和受光边优先于锈斑细节；
- 近景仍应能从阴影中辨认窗框分格。

### 6.7 `roof-tile-warm-black`：暖黑灰瓦顶

- 主体为暖黑灰而非纯黑；日照面可见灰绿或褐灰变化；
- 大色块负责整体坡面，法线／节奏贴图只辅助瓦片方向；
- 檐口和屋脊若近景轮廓不足，再由 GLB 或附加低面数几何补充；
- 禁止镜面湿瓦效果。

### 6.8 `moss-soft-olive`：柔和青苔覆盖

- 只作为遮罩混合层，不作为全物体独立平铺主材质；
- 色相控制在低饱和橄榄绿至灰绿；
- 边缘柔和、形状成片但不碎噪；
- 密度由位置和潮湿逻辑决定。

## 7. 赛璐璐明暗与水彩过渡

### 7.1 明暗层级

首轮采用“三层可读关系”，不把所有光照硬切成漫画色块：

1. **日照主色**：保持材质原有色相和较高明度；
2. **半影过渡**：宽度适中、边缘柔和，带轻微综合色偏移；
3. **阴影主色**：偏蓝绿、明度下降但保留纹理和结构。

直接光分层建议先以 `N·L` 的柔和阈值实现，而不是使用高对比硬阶梯。候选阈值与过渡宽度须在样板中调节；任何情况下不得使窗洞、走廊或檐下压成死黑。

### 7.2 水彩感的来源

- 基础色贴图中的低频手绘色差；
- 半影边缘的轻柔综合色过渡；
- 局部遮罩中的宽软边叠色；
- 雾和远景饱和度自然下降。

水彩感不来自全屏纸纹、抖动噪声、分辨率降低或持续闪动。摄像机移动时材质图案和阴影边界必须稳定。

### 7.3 阴影颜色

阴影通过环境光、半球光和综合色偏移共同形成，不直接把阴影乘成黑色。廊下与室内入口需保持可见层次，同时比室外日照面明确暗一档。

## 8. 光照、天空与雾

当前光照作为 v0.1 起点：

- 半球光：天光偏浅蓝，地面反射偏暖土色；
- 主方向光：高位、浅金色，方向保持稳定；
- 阴影：`PCFSoftShadowMap`，首轮维持 `2048 × 2048`；
- 天空与雾：统一为高明度青蓝，雾只用于远景空气透视。

实施要求：

- 太阳方向在同一批对比图中固定，不用移动太阳迁就单个材质；
- 近景建筑投影边缘可读但不刀切，远处自然柔化；
- 阴影贴图范围应尽量覆盖主要校园而不过度浪费精度；
- `shadow.bias` 与 `normalBias` 只解决阴影伪影，不用来漂浮阴影；
- 不使用晨雾、体积光柱或戏剧性云层；
- 后续树木完成后，叶影光斑单独设计，不能用全屏动画噪声替代。

## 9. 描边与结构线

描边用于帮助建筑结构在复杂光照下保持可读，不是把所有物体变成漫画线稿。

- 当前约 2 px 的结构描线可作为灰盒检查基线；正式样板须同时评估 1 px、1.5 px 和 2 px 的视觉效果。
- 优先描绘外轮廓、墙体转角、楼板边、柱梁关系、门窗框和重要台阶。
- 大面积共面分段、地面内部三角边和细小贴图旧化不得产生描线。
- 远景描线应减弱或消失，避免鸟瞰时形成黑色网格。
- 线色使用深灰绿或深暖灰，不使用纯黑；阴影面可稍深，日照面保持克制。
- 透明花格、细铁窗等高密度结构避免重复叠加粗描边，以免糊成黑块。

描边必须支持总开关，验收时同时提供开启与关闭版本。

## 10. 后期处理边界

v0.1 只允许轻量、可关闭的全局调整：

- 曝光和色调映射；
- 非常轻的综合色平衡；
- 必要时轻微降低远景饱和度；
- 经过样板证明必要的抗锯齿或轮廓合成。

第一轮不加入 bloom、景深、色差、胶片颗粒、纸纹、明显暗角和动态全屏噪声。若关闭后期后材质失去手绘感，应返回贴图、光照或明暗分层修正。

## 11. 首轮立面样板

### 11.1 样板范围

选择旧教室南立面的一间教室段作为第一轮样板，保留当前结构数据。样板至少同时展示：

- 严重老化但不阴森的石灰墙；
- 旧木门；
- 旧铁窗；
- 黑瓦屋顶与檐下阴影；
- 建筑前浅色旧水泥／土地面的衔接；
- 少量有原因的露砖、墙脚潮痕和青苔。

旧教室总尺寸仍为 C 级工作值，因此样板只确认画面语言、纹理尺度和材质关系，不把样板结果当作新的建筑尺寸依据。

### 11.2 必须提供的对照状态

1. 纯基础材质＋基础光照；
2. 加入赛璐璐柔和明暗分层；
3. 加入结构描边；
4. 最终综合色状态；
5. 鸟瞰距离和第一人称近景各一组；
6. 至少一张显示材质在檐下阴影中的可读性。

### 11.3 样板验收条件

- 第一眼感受是温暖、安静的旧校园，而不是废墟或新建卡通模型；
- 日照面、半影和阴影三档关系清楚，阴影中仍能辨认门窗结构；
- 墙面在 2–10 m 行走距离没有明显平铺重复、拉伸或接缝；
- 旧化区域数量克制，位置合理，不盖过建筑体量；
- 木、铁、石灰、水泥和瓦片仅靠大色块、粗糙度和适量纹理即可区分；
- 关闭描边与后期后，材质仍然成立；
- 鸟瞰时不会因纹理过密产生噪点或摩尔纹；
- 没有改变任何墙洞、尺寸、坐标和碰撞。

## 12. 性能与稳定性

- 相同材质族共享 `Material`、纹理和采样参数；只有确需独立颜色或遮罩时才克隆。
- 重复门窗和后续家具优先使用实例化或合批，但不得破坏独特遮罩的正确索引。
- 透明材质只用于确有透明需求的花格、玻璃或局部遮罩；普通旧化不得依赖透明叠面，以减少排序问题。
- Alpha 裁切纹样继续使用明确的 `alphaTest`，避免大面积半透明混合。
- 所有新增贴图必须有失败回退材质，加载失败时场景仍可诊断和行走。
- 调试面板至少应能切换：基础材质、风格明暗、描边、阴影、后期和旧化遮罩。
- 每轮修改后执行生产构建，并从鸟瞰、校门进入、操场、建筑近景和檐下行走视角回归检查。

## 13. 版本与确认流程

材质族或渲染规则的变更必须记录：

- 材质标识与版本；
- 使用对象；
- 贴图通道、分辨率和色彩空间；
- 米制覆盖范围／UV 方法；
- 粗糙度、法线和透明参数；
- 局部遮罩的使用原因；
- 鸟瞰与近景验收结果；
- 确认状态：`candidate`、`approved` 或 `deprecated`。

首轮旧教室立面样板确认后，应将通过的参数整理为 v0.2；未确认的候选值不得批量铺到全校园。

## 14. v0.1 实施顺序

1. 建立纹理缓存、材质库、统一调试开关和命名目录；
2. 建立米制纹理投射，先解决当前参数化 BoxGeometry 的逐段拉伸问题；
3. 制作旧石灰墙、旧水泥、旧木、旧铁、黑瓦与青苔六个样板材质；
4. 接入旧教室南立面样板；确认后扩展到完整南立面；
5. 调整基础光照与阴影可读性；
6. 接入可关闭的柔和三层明暗；
7. 调整结构描边并制作规定的对照视图；
8. 用户确认画面语言后，再扩展到一号楼、二号楼、厕所、宿舍和校园地面。
