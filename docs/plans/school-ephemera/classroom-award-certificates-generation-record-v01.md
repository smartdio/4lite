# 教室旧奖状生成记录 v0.1

生成日期：2026-08-17  
处理方式：Codex 内置图像生成工具的参考图生成模式＋ImageMagick 统一尺寸和 WebP 导出

## 用途与位置

- 用作八十年代学校教室内的旧奖状墙面贴图。
- 指定位置：教室后墙、后黑板上方。
- 本批只生产素材，不接入场景。

## 参考约束

- 横版、正面、平铺，完整纸张边缘可见。
- 保留参考中的旧纸、折痕、褪色套印、红星、帷幕／旗帜、麦穗花卉、下部线描和红色圆章语言。
- 大标题可读为“奖状”；正文使用不清晰的手写伪文字，不含真实姓名、班级和机构信息。
- 不生成墙面、相框、玻璃、胶带、图钉、投影、现代标志或水印。

## 变体

1. 红色帷幕、星章、麦穗、向日葵与工业线描。
2. 红旗红星、玉米花卉与齿轮书本纹样。
3. 红色垂幔、麦穗、校舍、课本与铅笔。
4. 星芒章、麦穗向日葵、火炬书本与工厂／校舍线描。

## 最终提示规格

`Use case: historical-scene game texture`

以两张用户参考作为年代、材质和版式依据，生成四张晚七十至八十年代小学奖状。统一为 `4:3` 横版正视扫描质感；纸面泛黄，有轻微横竖折痕、磨损、污点和不均匀旧印刷。顶端和边缘使用红星、红色帷幕／旗帜、麦穗、花卉与年代线描装饰，中部保留题名和正文区。标题为略褪色的“奖状”，正文为模糊伪汉字手写笔画，配不可辨认的红色圆章。不得出现现代设计、真实个人信息、墙面样机或新增水印。

## 输出

- 运行时 WebP：`public/assets/textures/school-ephemera/posters/classroom-awards/`
- 拼图预览：`docs/previews/school-ephemera/classroom-award-certificates-v01.png`
- 运行时统一为 `1600 × 1200`、WebP 质量 90。
