# 八十年代小学黑板报生成记录 v0.1

生成日期：2026-08-17  
处理方式：Codex 内置图像生成工具的参考图生成模式＋ImageMagick 粉笔层透明度提取和 WebP 导出

## 使用位置

- 每个教室后墙的后黑板。
- 黑板报覆盖黑板可书写区域，不覆盖木框和粉笔槽。
- 本批只生产贴图和预览，不接入场景。

## 共用生成规格

`Use case: historical-scene`

生成晚七十至八十年代中国小学后黑板报。以用户四张参考作为年代、粉笔媒介和分栏方式依据，不复制水印、黑板框、墙面或原文。统一为 `8:3` 宽横构图、正视无透视；包含一个清楚的大标题、两至三个正文栏、粉笔花边和少量符合主题的学生手绘插图。正文为多行不可辨认的伪汉字粉笔笔画。粉笔使用褪色白、浅黄、粉红、浅蓝和浅绿，笔触干燥断续并带少量擦除残留。不得出现现代图标、照片、印刷纸张、标志或水印。

## 主题变体

1. `欢迎新学期`：国旗、枝叶、打开的书、火箭、星星和小型值日栏。
2. `五讲四美`：手印式花朵、和平鸽、红领巾结、枝叶与三栏文字。
3. `热爱劳动`：齿轮麦穗、向日葵、扫帚／水壶、工厂线描和植树学生。
4. `书是人类进步的阶梯`：读书学生、叠放课本、打开的书、铅笔、花叶和和平鸽。

## 透明叠加处理

内置生成结果带深色预览底。导出时以亮度生成透明度：深色黑板区域变为透明，彩色粉笔笔画保持较高不透明度，微弱粉尘保留低透明度。运行时因此可以覆盖任何现有黑色／墨绿色黑板材质，而不会替换原黑板的颜色、磨损和法线细节。
