# 个人本地纪录册 v0.1

日期：2026-08-31

## 范围

- 只记录当前浏览器中的一位玩家，不做账号、联网排名、跨设备同步或多存档。
- 数据使用项目统一 `localStorage` 容器的 `personalRecords` 命名空间，结构版本为 1。
- 清除网站数据时，个人纪录一同清除。

## 统计口径

- 参观房间：玩家进入教室有效空间并停留至少 800 ms 后，按房间 ID 永久去重。
- 看过书籍：打开课本、练习册或连环画查看器后，按内容 ID 去重；同一本书在多张课桌出现只计一本。作文纸另行记录，不并入书籍数。
- 看过物件：打开 3D 查看器后，同时保留“种类数”和“实例数”；总览显示种类数。
- 玩过游戏：只在第一个实际玩法动作发生时记录，仅进入附近或看教学不计数。
- 最佳纪录：分数、距离、高度、连续数和进度取最大值；失误次数和魔方完成步数取最小值；完成次数累加。
- 写入时机：只在首次实际游玩、最佳值变化或完成次数增加时持久化，连续按键、拖动或未刷新纪录的动作不重复写 `localStorage`。

## 三项神秘任务

1. 卜卜星零食：三包共用一项任务，显示 `0/3`—`3/3`，只有三包全部打开过才完成。
2. Octopus 掌机：第一次打开掌机时完成发现。
3. Fire 掌机：第一次打开掌机时完成发现。

未发现的掌机在纪录册中仅显示“神秘掌机／神秘物件”，不显示名称和所在房间。旧版本已有掌机最高分时，自动视为已发现并迁移纪录。

## 展示与交互

- 漫游和鸟瞰状态的右上角，在“鸟瞰／第一人称”按钮左侧常驻显示明确的“个人记录”按钮，桌面和触屏点击后直接打开纪录册。该按钮与视角按钮共用一张 CanvasTexture，不新增纹理请求。
- 桌面端原有 `Esc` 暂停菜单中的“个人纪录册”入口继续保留。
- 纪录册是 Three.js 全屏浮层，使用暖色作业本纸张、红色装订线和盖章，不新增现代 HTML 界面。
- 三个分页为“总览／游戏纪录／神秘任务”。总览显示四项数量、最佳纪录摘要和神秘发现。
- 界面只保留一张驻留 CanvasTexture，打开、切换分页或改变窗口尺寸时重绘，不在每帧上传纹理。

## 实现入口

- 数据层：`src/state/personal-records.js`
- WebGL 纪录册：`src/ui/personal-record-book.js`
- 玩法、房间和查看器接线：`src/main.js`
- 两台掌机事件：`src/interactions/octopus-handheld-game.js`、`src/interactions/fire-handheld-game.js`
- 魔方步数事件：`src/interactions/rubiks-cube-game.js`
- 专项验收：`tests/performance/personal-records.spec.js`
