# 1号教学楼外廊栏杆花纹辨读 v0.3（等待亲历者草图确认）

## 本版状态

v0.1 的“独立宝瓶柱”和 v0.2 的“A—B相反方向孔洞交替”均已被亲历者否定。本版不再给花纹定型，只记录两张放大图能够直接支持的视觉关系，以及仍无法从模糊影像可靠确定的部分。

## 重新辨读后的关键修正

上一版最大的错误，是把照片中的深色负空间（孔洞）直接当成了花纹构件。应当反过来追踪黄色实体肋：插画更像是同一种环状／拱环状实体单元连续重复；环内形成较大的竖向圆角孔，相邻实体单元之间又自然留下较窄的尖顶或收腰孔。这些不同外形的孔不等于两种交替构件。

## 两张图能直接支持的关系

1. 上部不是简单的独立竖栏，也不是一排彼此分离的瓶形件，而是横向连续相接的实体花格。
2. 插画中可辨认出重复的黄色环状或拱环状轮廓；每个重复单元内部有一个较大的竖向圆角孔。
3. 相邻重复单元之间存在较窄的尖形／收腰负空间，它是单元拼接后形成的间隙，不应单独命名为另一种构件。
4. 主花格的上、下两侧都能看到浅拱形负空间；这些负空间与中部重复单元存在对位关系，但现有照片不足以确认准确对位。
5. 历史照片中最下方能辨认出一排较方正的短孔，但无法仅凭该照片确定它与上部单元是一体成型、上下错位，还是被水平肋分成两个图案带。

## 暂时不能确认

- 单个重复实体究竟是完整闭合环、开口拱环，还是两条相交曲线形成的视觉环。
- 上方竖缝、上方浅拱孔、中部大孔、下方浅拱孔和底部短方孔的准确水平对位。
- 每个柱间有多少重复单元，以及端部如何收口。
- 黄色轮廓在插画中的夸张程度；不能从插画直接提取曲率。

## 下一步资料要求

最有效的确认资料是一张只画一至两个重复单元的正立面草图，并明确：

- 实体水泥部分涂实色；
- 镂空部分留白；
- 标出上下方向；
- 若上下两排错位，画出至少两个连续单元。

在草图确认前，不制作栏杆二维模板，也不写入3D程序参数。
