# 大榕树叶片受光调整计划 v0.1

日期：2026-08-22
计划分支：从 `codex/smooth-2k-rendering` 的已提交状态新建后续分支

状态：阶段 A 的第二轮 A2 已获用户实机确认并封板；阶段 B 叶簇法线与 A3 阴影候选不启动。

## 目标与边界

- 盛夏日照下，树冠朝阳面应出现清楚但不过曝的亮叶层次，背光面继续保留深度。
- 只调整大榕树叶片，不提高全局太阳、曝光、室外环境光或全场 GTAO。
- 保留现有完整榕树、488 张叶簇卡片、Alpha Mask、地面投影、单一完整模型和无 LOD 边界。
- 第一阶段不增加纹理、材质数量、draw call 或后处理 Pass；未获用户视觉确认前不更新截图基线。

## 已确认现状

- 正式资产为 `public/assets/models/banyan-tree/banyan-tree-scene-optimized.glb`，叶片材质是 `MAT_Banyan_Leaves_Natural_Flat_V4`，属于受光 PBR 材质，并非 Unlit。
- 叶片网格带顶点法线，但没有叶片法线贴图；一张平面叶簇内的多片叶子共享卡片方向，细粒度朝向差异无法由几何法线表达。
- 叶图主色约集中在 `#2b521b` 至 `#456f24`，高亮绿色像素很少，底色本身偏暗。
- GLB 原始叶材质使用同一叶图作为 Emissive Map，Emissive Factor 约为 `0.42`；运行时为避免树叶自发光，在 `loadBanyanAsset()` 中将它强制清零。
- 运行时叶材质粗糙度为 `0.92`，GLB 镜面强度约 `0.10`；两者共同抑制叶面高光。
- 叶片同时投射和接收太阳阴影，并叠加室外 GTAO。密集卡片内部的阴影和遮蔽会进一步压暗树冠。
- 实景太阳强度 `4.7`、曝光 `1.12`，建筑和地面亮部已经足够明亮；问题不应通过全局增亮解决。

## 修改方案

### 阶段 A：运行时材质候选，优先执行

在榕树加载器中集中建立叶片光照配置，并提供仅开发／测试环境可用的候选切换。以下数值都是待实景比较的工作值，不是已确认定值：

| 候选 | 叶片颜色倍率 | Roughness | Specular | 叶图补光 | 用途 |
| --- | --- | ---: | ---: | ---: | --- |
| A0 现状 | `1.00` | `0.92` | `0.10` | `0` | 对照基线 |
| A1 高光 | `1.00` | `0.68` | `0.30` | `0` | 单独确认阳光亮面是否足够 |
| A2 推荐综合 | 暖绿约 `1.12–1.20` | `0.68–0.74` | `0.25–0.32` | `0.04–0.08` | 提亮底色，同时保留朝阳／背光差异 |

实施约束：

- 继续使用现有 `MeshStandardMaterial`／`MeshPhysicalMaterial`、Alpha Test 和双面叶片。
- 不直接恢复 `0.42` 补光；它会同时抬高亮面和暗面，使树冠继续缺少方向层次。
- 首轮保持叶片 `castShadow=true`、`receiveShadow=true`。如果 A2 仍因叶簇内部过暗，再单独比较“继续投射地面阴影、叶片不接收场景阴影”的 A3 候选；不能直接作为默认值。
- 将最终叶片参数写入性能配置或独立榕树材质配置，避免散落魔法数；测试接口只用于候选比较。

### 阶段 B：叶簇法线，按需执行

只有阶段 A 已能提亮颜色但单张叶簇仍像平面时，才修改 `assets/source/blender/banyan-tree-source-v42-branch-tip-leaf-clusters.blend`：

- 把叶簇卡片法线向树冠外侧和上方适度弯曲，使同一树冠不同区域形成稳定的顶亮、侧次、底暗层级。
- 优先重算法线，不增加叶片卡片数量；若仍不足，再评估小尺寸叶片法线贴图。
- 重新导出后保持现有树高、冠幅、位置、碰撞、三角面级别、Meshopt 压缩和纹理预算。
- 新 GLB 先作为候选资产接入，不直接覆盖正式文件；三视角通过后再替换。

## 验证与验收

固定检查 `focusBanyan()`、`focusBanyanFromGround()` 和 `focusBanyanBase()`：

1. 鸟瞰朝阳树冠应出现成片但不连续涂白的亮叶，能读出树冠团块高低。
2. 地面仰视时，顶层和外缘亮于树冠内部；树下仍有阴凉感，枝干不能被叶片补光染绿。
3. Alpha 边缘不新增白边、闪烁或硬矩形；远景树冠轮廓和密度不改变。
4. 地面、宿舍和树干上的榕树阴影继续存在；不得影响其他操场树材质。
5. Renderer 纹理数、场景 draw call 和模型三角面不因阶段 A 增加；稳态帧时间不得出现可测回退。
6. 至少运行榕树定向回归、`npm run build`、`npm run perf:build` 和 `npm run build:test`。

最终候选由用户在实际校园画面确认。确认前保留 A0 一键回退，不更新视觉基线。
