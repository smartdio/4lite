## 2. 第一版模型应表达

- 两间教室组成的一层长条体量。
- 大片剥落的石灰饰面，以及剥落处显露的老旧砖墙。
- 明确的双坡屋顶、长向屋脊、黑瓦轮廓及一定的檐口外挑。
- 檐下少量可辨认的木构件，使屋顶读作木屋架体系。
- 两个重复的“门—窗—窗—窗—门”正面单元，以及每间四扇较小背窗。
- 与围墙、厕所、沙池和未确认设施 A 的正确位置关系。

## 3. 明确不制作

- 可进入的教室内部。
- 完整室内隔墙、课桌、黑板和室内照明。
- 从室内观察所需的完整屋架节点。
- 逐片高精度瓦片、复杂破损模拟或近景级材质。
- 没有记忆依据的装饰、现代门窗或新式修缮构件。

## 4. 当前尺寸状态

校园总图早期暂按约 `26 × 7.5 m` 占位，建议长度范围 `22–30 m`，可信度 C。这个尺寸仅来自总图相对比例，不能因本次草图而提升可信度。

两间教室在 v0.1 图纸中暂按等大处理，中间分隔墙作为建筑中线候选；这是为了形成可调整的第一版，不锁定为事实。

## 5. 尚可后续校准但不阻塞建模

1. 两间教室是否大致等大，以及整栋楼的大概长度和进深。
2. 两端山墙是否有开口。
3. 门窗的材质、分格和大致尺寸。
4. 石灰饰面的原始颜色，以及墙脚是否有不同处理。

正面朝南和门窗排列已经确认。其余问题可在出现新记忆或照片时再校准，不需要继续追问室内细节。

## 6. v0.1 图纸采用的工作值

- 建筑外包长宽暂沿用校园总图的约 `26 × 7.5 m`，可信度 C。
- 两间教室暂按等大处理，中隔墙位于建筑中线，可信度 C。
- 外墙厚度、门窗尺寸与间距仅作图示占位，不作为确认数据。
- 墙身／檐口高度采用亲历者估算的约2.7 m，可信度 A-。
- 屋脊总高度不再使用原先偏高的5.0 m工作值；待屋面坡度获得依据后联动确定。
- 木屋架图只表达“木斜构件＋横梁＋支撑”的结构逻辑，不锁定具体传统屋架节点。

图纸已足以支持后续简化外部模型；剩余未知项不会阻塞其他建筑的讨论。

## 7. 屋顶外观实现 v0.1

2026-08-10：根据亲历者指出的“坡面像两张纸、缺少瓦边、檐下木梁和屋脊”问题，旧教室屋顶已从单层三角壳改为简化但有构造层次的外部模型：

- 两片坡屋面具有约 `0.14 m` 的视觉厚度；
- 南北檐口增加半圆弧形瓦片端头，不在完整坡面逐片建瓦；
- 屋脊增加连续的分段半圆脊瓦；
- 檐下增加连续木檩和重复木椽尾；
- 两端山墙增加沿坡封檐木板和三角山墙面；
- 黑瓦基础色和瓦片节奏继续由手绘贴图负责。

其中瓦当半径、脊瓦半径、木构件截面和重复间距均为 C 级视觉工作值，只用于表达资料明确确认的构造类型，不代表已经确认具体瓦型或传统木屋架节点。建筑占地、檐口标高、屋面坡度、门窗位置和碰撞均未改变。

## 8. 南立面开口更正与实现

2026-08-10：亲历者更正每间教室正面开口为两侧各一门、中间三扇窗，即“门—窗—窗—窗—门”；此前的“门—窗—门”结论作废。

- 四扇门复用一号楼现有左右铰链木门 GLB，保持米制原尺寸；
- 每间左门使用左铰链版本、右门使用右铰链版本；
- 三扇中窗采用不可交互的简化内嵌铁窗格，当前为三列两行；
- 窗格只以深色后衬和约6 cm视觉退距表达内嵌，不切穿墙体；
- 门窗中心间距、窗宽和窗格分法仍为 C 级外观工作值；
- 旧教室继续不可进入，整体建筑碰撞不变。

浏览器实景验收已确认：两间教室各自完整呈现“门—窗—窗—窗—门”，四扇复用门模型均加载成功，窗格的浅内嵌关系可辨认。

2026-08-10：旧白石灰墙贴图由南立面延伸至东西两端完整侧墙，包括檐口以下矩形墙面和坡顶三角山墙；封檐木板和屋面结构保持原有做法。
