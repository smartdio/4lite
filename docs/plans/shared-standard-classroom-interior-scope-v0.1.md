# 一号楼／二号楼共用标准教室内部模块｜范围记录 v0.1

## 当前决定

- 教室内部布局暂缓讨论与制作，当前阶段优先完成校园、建筑外壳、走廊、楼梯、门窗和屋顶。
- 一号教学楼与二号教学楼的标准教室内部布局基本统一。
- 后续不为两栋楼分别重复设计，而是建立一个共用的“标准教室内部模块”，再根据楼栋年代和门窗材质做少量变体。

## 后续统一讨论内容

- 黑板、讲台和教室朝向。
- 课桌椅的年代样式、数量、行列和间距。
- 教师桌、清洁角、储物柜等固定陈设。
- 地面、墙裙、天花、灯具、吊扇和明装电线。
- 门的开启方向、常开状态和五金。
- 木窗／铁窗的开启、插销、限位和玻璃状态。
- 两栋楼需要保留的少量材质差异。

在该模块正式讨论前，不以临时家具或现代教室布局填充任何教室。
