# 厕所整体重制计划 v0.1

日期：2026-09-01  
状态：亲历者已确认并正式应用；默认场景使用 2.35 m 中央净开口＋3.10 m 内墙＋25 cm 平面文字＋完整背墙版本

## 1. 结论

厕所的正式事实来源是 `GLB/厕所.glb`；`GLB/` 内既有 Blender 厕所文件不正确，不得作为重建依据。现已通过 Blender MCP 从原始 GLB 新建独立源文件，在保留原始网格、UV、材质和三张贴图的前提下，仅移动南侧两片屏风墙的独立几何岛。主体仍是单网格／单 primitive，因此本轮没有把艺术细节重新臆造为语义分件。

2026-09-01 获亲历者确认后，候选已替换正式资产 `public/assets/models/toilet/toilet-game-optimized-v01.glb`。2026-09-02 发现北侧整面背墙在原始 GLB 中缺失，已按两侧外柱内边界补齐并保留檐下通风带；默认 URL 缓存版本升级为 `v=10`。碰撞体和不可进入边界仍沿用原场景配置，上一正式版归档在 `archive/toilet-pre-rear-wall-v11/`。

## 2. 新模型必须保留

- 运行定位继续以中心约 `[5.34, -58.67]`、东西向约 `6 m`、南北向约 `4.8 m` 为替换边界；用户已确认 `6 × 4.8 m` 可接受，但仍属于回忆还原工作值，不写成实测尺寸。
- 一层、低矮双坡黑瓦顶、无窗、连续檐下通风空隙和四周白灰砖柱。
- 背墙、左右侧墙和中央正墙的既有入口拓扑；女厕在左、男厕在右；小型褪色手写标识的方向与位置关系。
- 更破旧的石灰墙、局部露砖、潮湿青苔和当前校园水彩材质方向。
- 继续作为不可进入建筑，沿用约 `6 × 4.8 m` 的简化整体碰撞边界，不制作内部厕位、排水或交互。

## 3. 本轮新增校准目标

- 两片南侧屏风墙应比当前模型更短。
- 校准时同时满足：从校园正面不能直看男女两端门洞；站在内部门口位置，可以斜向看见操场。
- 屏风墙的具体长度、内端位置和斜视角仍未知。第一轮灰盒只做候选，不把截图笔画当作量尺。
- 原始 GLB 的中央净开口约为 `1.5032 m`。Gate A 已制作 `2.20 m`、`2.35 m`、`2.50 m` 三个候选，当前推荐 `2.35 m` 作为平衡值；这些仅为画面比较工作值，不能写成历史尺寸。
- 第二轮左右各延伸约 `0.09 m` 因变化不明显而作废；第三轮从干净的 `2.35 m` 候选重建，把后方中央内墙由约 `2.30 m` 加宽到约 `3.10 m`，即左右各延伸 `0.40 m`，外屏风中央净开口不变。
- 左右屏风原有“女／男”立体字拓扑已删除：共移除 `475` 个顶点和 `890` 个三角面，替换为两张真正共面的正面墙。字样继续来自贴图，不再使用凸起几何。
- 第四轮直接复用原手写字像素，把“男”从约 `152 px`、“女”从约 `146 px` 等比缩至 `57 px`；按墙面 UV 实尺分别约 `24.98 cm` 与 `25.21 cm` 高。旧大字区域已在底色、法线与金属／粗糙度三张贴图中同步抹平，避免残留法线凸起。
- 第五轮补齐北侧整面背墙，工作尺寸约 `5.559 × 1.898 × 0.242 m`；墙体略压入左右外柱以消除漏光，顶部保持原有连续通风空隙，UV 复用既有无文字旧灰墙区域。

## 4. 制作与资产结构

1. Blender MCP 源文件为 `assets/source/blender/toilet-rebuild-source-v01.blend`，包含不可改参考体与 `2.20 / 2.35 / 2.50 m` 三个候选；默认显示 `2.35 m`。
2. 本轮只缩短南侧屏风：独立几何岛的内端向外移动，外侧回墙锚点不动；保留原始黑瓦、旧石灰、露砖、青苔、小字、UV 和材质。
3. 结构确认后才继续材质或几何优化，不提前重做未被指出的问题。
4. 发布候选继续保持一个主要网格和一套材质，不增加 LOD 或低模替代路径。全局 Decimate 与误差约束 Simplify 均因屋顶锯齿或平墙三角阴影被否决。
5. 正式来源候选 `artifacts/toilet-rebuild/toilet-gap235-inner-plus40-text25-flat-rear-v11.glb` 为 `49,122` 三角形、`41,122` 顶点；三张贴图为 `1024² WebP` 并使用 Meshopt，文件 `1,423,680 B`。
6. 临时 `?toiletRebuildCandidate=gap235` 加载分支已移除；默认场景直接加载正式重建版。
