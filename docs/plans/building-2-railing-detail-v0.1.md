# 二号教学楼栏杆构造 v0.1

依据：历史正面照片、亲历者说明及 `013-building-2-railing-section-sketch.jpg`。

## 已确认的几何关系

1. 栏杆由连续顶部扶手、连续底梁和重复的竖向构件组成。
2. 竖向构件在正立面上呈笔直的窄条，正面基本是平直面。
3. 侧面以亲历者草图左图为准：一边基本竖直，另一边由较长的上斜边、位置偏下的外凸折点和较短的下斜边组成。
4. 整体侧视轮廓近似不对称五边形，不是菱形；外凸折点明显低于构件高度中点。
5. 栏杆自身不设置粗大柱；教室两窗之间的粗柱属于教室外墙，不属于栏杆。
6. 单根竖件朝院正面的可见宽度暂定约0.10 m；这是亲历者估算值，不是测绘值。

## 建模建议

- 第一版保持正面宽度基本不变；侧面直接按左图的不对称多边形轮廓建模。
- 一侧保持近似竖直，另一侧设置偏下的折点；不得自动镜像或规整成菱形。
- 顶、底端分别嵌入扶手和底梁，不增加花头或装饰节点。
- 第一版模型把正面宽度设为0.10 m，并保留为可调整参数；侧向进深和间距尚不锁定。
