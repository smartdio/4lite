# 校园大环境灰盒范围 v0.1

确认日期：2026-08-08  
依据：校园总平面 v0.2、各建筑资料卡及亲历者当前制作优先级  
目标：先完成主要建筑与大环境，验证校园整体比例、地形、视线和行走关系。

## 1. 本阶段制作内容

### 主要建筑

- 一号教学楼：按已确认的 U 形主体、两层、主楼与翼楼关系制作可调整灰盒。
- 二号教学楼：按三层、四间教室／层、中央楼梯和连续外廊关系制作可调整灰盒。
- 旧教室：制作不可进入的一层两教室外部体量、黑瓦双坡顶和基本门窗。
- 厕所：制作不可进入的约6 × 4 m外部体量、黑瓦顶、通风带及已确认的屏风入口。
- 教师宿舍：制作不可进入的两层三开间外部体量、一层无走廊、二层西侧外挑走廊及南墙露天楼梯。

### 大环境

- 校园不规则边界与校门开口。
- 主要操场和建筑之间的基本空地。
- 操场东侧约1 m高的连续高台及土坡。
- 厕所、沙池所在低地与东侧高台之间的高差。
- 旧教室前活动场地的上下两片沙地。
- 上部双杠、下部高低单杠和天梯只制作简化占位构件。
- 西侧四张砖砌底座＋水泥板台面的固定乒乓球桌。
- 主要可通行路线和建筑外部碰撞范围。

## 2. 明确延后

- 其他树木的树种、树形、准确位置和精细模型。
- 花坛、花基植物和灌木细节。
- 旗杆底座、旗杆台阶与表面构造。
- 水泥滑梯的准确造型、台阶和近景细节。
- 细叶榕的精确树根、气根、树冠与土墩细节；本阶段仅保留土墩和树木体量占位。
- 沙池的精确边缘、沙层和使用痕迹。
- 建筑旧化、青苔、裂缝、标语、门牌及排水细节。
- 标准教室内部、课桌、黑板和其他室内陈设。
- 可开合门窗、声音、剧情和交互细节。

## 3. 第一版灰盒必须通过的检查

1. 从校门进入时，一号楼及其 U 形关系是否正确。
2. 穿过一号楼中央通道后，两栋教学楼间距和主要操场尺度是否合理。
3. 从操场看向东北侧时，厕所、沙池、东侧高台和旧教室的高差关系是否清楚。
4. 旧教室前器械场地、教师宿舍和细叶榕土墩是否形成正确的东侧空间层次。
5. 教师宿舍西向门窗、二层走廊和南墙露天楼梯方向是否正确。
6. 五栋建筑的相对高度、长度、进深和屋顶轮廓是否符合记忆。
7. 校园围墙和主要通行区域是否存在明显冲突或无法通过的位置。

## 4. 实现原则

- 不沿用根目录早期被否定的 Three.js 空间和尺寸结果。
- 以 `campus-plan-v0.2.svg` 和各建筑最新资料卡为数据依据。
- 所有工作尺寸集中参数化，便于亲历者根据行走感受调整。
- 不用美术细节掩盖比例和地形问题。
- 灰盒确认后，再分批补充树木、花坛、旗杆台、滑梯、材质和年代细节。
- 灰盒从第一版开始遵循 `art-direction-v0.1.md` 的盛夏手绘动画感：用简洁色块、高位阳光、清晰树影和蝉鸣占位验证情绪，但不提前制作最终美术。

## 5. 当前判断

现有资料已经足够进入“校园大环境第一版可调整灰盒”。未确认的细节不会阻塞主要建筑和地形验证，但仍需在模型中保持可替换、可调整状态。
