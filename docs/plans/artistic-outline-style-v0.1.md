# 校园艺术描边风格规范 v0.1

## 1. 目标

艺术描边用于强化校园建筑、地形和设施的关键结构，使画面具有手绘插画中的笔触感。描边是材质、光影和环境遮蔽之外的辅助层，不替代真实结构，也不把整个场景变成统一漫画线稿。

首版只覆盖约 15%–25% 的可见边缘。判断标准是“这条线是否帮助玩家理解结构”，而不是“这里是否存在几何边”。

## 2. 边缘层级

### 2.1 一级主轮廓

- 建筑屋顶外轮廓、屋脊和主要屋檐转角；
- 建筑体量的主要外墙转角；
- 楼梯、平台和外挑走廊的外侧轮廓；
- 东侧连续高地的主要顶面边界；
- 厕所、教师宿舍、旧教学楼和沙池的整体剪影；
- 升旗台等具有识别意义的独立设施轮廓。

一级线在近景中承担主要读形作用，允许稍深、稍粗，但禁止使用纯黑。

### 2.2 二级结构线

- 门窗最外层框线，不描内部每一格窗花；
- 阳台和走廊的上下边缘；
- 柱、梁、楼板的关键交接；
- 楼梯斜板、平台和少量主要踏步；
- 屋顶瓦面的大转折，不描每一片瓦。

二级线比一级线更细、更淡，并在远景中优先衰减。

### 2.3 禁止主动描边

- 每一根栏杆、每一格窗花和其他高密度重复构件；
- 水泥污渍、裂缝、水彩斑和地面纹理边缘；
- 地面内部三角边、共面拼接线；
- 树叶贴片和细碎枝叶；
- 光照阴影边缘；
- 建筑底部整圈均匀黑线；
- 因几何重叠或穿插产生的伪边缘。

## 3. 线条视觉规范

- 亮部主线采用深暖褐灰，暗部可逐步转向紫蓝灰；
- 不使用纯黑，不使用发光描边；
- 一级线近景目标宽度约 1.6–2.3 px，远景约 1.0–1.6 px；
- 二级线近景约 0.9–1.55 px，远景应显著减弱；
- 一级断续笔触透明度建议 64%–84%，二级线 32%–58%；连续底线保持更淡，避免形成纯漫画黑框；
- 线条保留 10%–20% 的自然断笔，断点长度和间隔不得完全规律；
- 笔触扰动使用固定种子，镜头静止时不得闪烁或游动；
- 扰动保持低频、低幅度，不把直线扭曲成明显波浪；
- 线条必须贴合结构，不得形成悬浮光环或穿过前景物体。

## 4. 技术策略

采用混合式方案：

1. 关键程序化构件使用世界空间结构笔触。提取满足角度阈值的几何边，生成一层淡连续底线和一层不规则断续笔触。
2. GLB 建筑只为经过筛选的整体剪影和长结构边生成笔触，不直接描绘模型的全部三角边。
3. 如后续需要屏幕空间辅助，只允许补充整体剪影；不得直接使用默认发光式 `OutlinePass`。
4. 描边作为独立渲染层，支持总开关，并独立于 GTAO、阴影、材质和色调映射。
5. 线条随机性由对象名称、边序号和固定种子决定，不使用逐帧随机数。
6. 线宽必须使用屏幕像素宽度实现，不依赖浏览器通常固定为 1 px 的基础 WebGL 线段；窗口变化时同步更新描边分辨率。
7. 教室门洞、窗洞的轮廓独立于门扇和窗扇模型生成，并分别贴合墙体内、外表面；门窗开启后洞口线仍须完整保留。

## 5. 距离与密度规则

- 第一人称近景显示一级线和经过筛选的二级线；
- 中景保留一级线，二级线透明度降低；
- 鸟瞰视角只保留屋顶、建筑体量、高地边界等一级线；
- 细栏杆、窗格和瓦片无论距离多近都不自动生成密集轮廓；
- 单段短于约 0.25–0.35 m 的自动边线默认舍弃，防止细碎噪声。

## 6. 首版实施范围

- 一号楼 U 形屋顶及主要走廊收边；
- 二号楼屋顶、走廊主梁；
- 一号楼、二号楼全部门洞与窗洞的内外双面轮廓；
- 一号楼前后走廊柱、教室分隔柱、转角柱、两翼内外柱，以及二号楼主要框架柱；
- 一号楼、二号楼主要楼梯斜板与平台；
- 一号楼、二号楼楼顶外延、檐口和主要屋顶转折；
- 东侧连续高地顶面主边界；
- 升旗台等少量独立设施。

厕所、教师宿舍和旧教学楼的 GLB 仅提取较长、转折明确的结构硬边，用于补充门窗框、柱边、整体剪影和屋檐；瓦片、窗格、小五金和三角面拼接不参与描边。沙池仍以地面材质和水泥边界读形，不加入建筑式密集轮廓。

## 7. 验收

- 鸟瞰下建筑仍以色块和光影为主，不形成黑色网格；
- 第一人称下屋顶、楼梯和平台关系更清楚；
- 线条存在轻微断笔和浓淡变化，但静止时完全稳定；
- 栏杆、窗格、树叶和地面纹理没有被重复描黑；
- 关闭描边后，材质和光影仍能独立成立；
- 描边不出现穿墙、悬浮、闪烁或深度冲突。
