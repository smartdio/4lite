# 热血躲避｜纯 3D 构图样张 v01

2026-09-05。独立静态 Three.js 构图，等待用户对实际画面进行视觉确认。

## 已落实的方向

- 方块人物、纯色几何校园、平滑抗锯齿、暖日照和清晰阴影。
- 用户本轮指定游戏名为 **热血躲避**；英文样张暂用 **Hot-Blooded Dodge**。
- 最新镜头按用户反馈改为**居中透视**：`PerspectiveCamera`，垂直视场角 38°，位置 `[0,9.11,37]`，看向 `[0,2.2,11.2]`，俯角约 15°。镜头位于球场中线，左右投接者保持同深度和对称透视；边线向中央消失点收拢。人物与投接空间为主体，教学楼只作为背景，允许按构图裁切。
- 二号楼完整几何仍使用 `CAMPUS.buildings.building2` 的尺寸，保留三层、每层四教室、中央折返梯、首层无栏杆、二三层连续栏杆、灰银窗框、木门及基座。相机裁切不删除楼体、不做 LOD。
- 四个原创人物：蓝队两端投接，红队中间躲避；白球、短尾迹、地面投影和接应者标记均为几何体。
- 人物按用户指定的热血高校式大眼方向调整：大方眼白、深色瞳孔和粗眉，投手自信咧嘴、接应者专注、躲避者分别惊讶和坚定。面部均为共享纯色方块几何，没有增加图片贴图；压浅鼻子并提高刘海，避免侧视时遮住眼睛或混淆眉毛。原镜头、人物比例、站位和动作保持不变。
- HUD 使用 WebGL 平面和一张预先生成的双语文字图集。英文复用项目 Fusion Pixel 字体；中文使用完整的系统中文粗体，避免子集缺字时混用字形。所有可见界面都在同一个 WebGL canvas 内。

## 启动与构建

从仓库根目录运行（使用项目已有 Three.js／Vite 依赖）：

```sh
node node_modules/vite/bin/vite.js --config previews/dodgeball-v01/vite.config.js --configLoader native
```

预览地址：<http://127.0.0.1:6176/>；英文直达：<http://127.0.0.1:6176/?lang=en>。

```sh
node node_modules/vite/bin/vite.js build --config previews/dodgeball-v01/vite.config.js --configLoader native
```

独立构建产物在 `artifacts/dodgeball-v01/site/`。该入口不在校园正式 Vite 构建列表中。缓存和构建产物均位于已忽略的 `artifacts/`，没有新增校园发布资源。

预览支持右下角语言切换或 `L` 键。暂停按钮／`Esc` 展示静态暂停样式，点击继续。退出按钮／`X` 收起 HUD 以查看纯场景，点击画面恢复；这里没有正式校园进入／返回流程，也没有游戏物理。

## 样张与检查

截图在本地目录 `docs/previews/dodgeball-v01/`：

- `hot-blooded-dodge-v01.png`：1920×1080 中文主样张。
- `hot-blooded-dodge-960-v01.png`：960×540 真实浏览器尺寸检查。
- `hot-blooded-dodge-en-v01.png`：英文布局检查。

使用 ego-browser 在真实 Chromium WebGL 中检查：两种语言标签均完整；四名角色互不遮挡且均在画内；球可见且未被人物覆盖；HUD 不覆盖角色或球；暂停／继续与语言点击有效；没有浏览器错误。两种尺寸都已实际截图目检，不更新校园视觉基线。

双语及暂停图层首屏预热后，连续切换语言 20 次，GPU 分配保持 70 个 geometry／2 张 texture，不继续增长。

场景主颜色通道实测 62 次绘制／29,476 三角形；连同 HUD 为 82 次绘制／29,516 三角形。大眼表情增加 26 个方块、312 个三角形，没有增加材质或绘制调用。初始化另绘制一次阴影贴图，之后只在窗口／界面变化时重绘，静态场景不持续运行动画循环。

完整楼体为 24,636 三角形、10 个材质批次；四名小人为 241 个方块实例、32 个材质批次。全场景共 30 个共享纯色材质，世界材质图片贴图数为 0。GPU 纹理包含一张 2048×1024 的双语 HUD 图集和一张 2048×2048 阴影贴图；唯一外部美术资源请求是约 4.14KB 的既有字体。

独立 Vite 生产构建通过。此次没有接入正式校园或发布资源，因此未执行依赖完整校园私有资产的正式校园全量构建、性能构建或回归测试。
