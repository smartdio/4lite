# 4Lite pixel UI font subset

`4lite-fusion-pixel-12px-ui-v02.woff2` is a UI-focused subset of
Fusion Pixel Font 12px Monospaced Simplified Chinese, release `2026.08.11`.

- Upstream: https://github.com/TakWolf/fusion-pixel-font
- Copyright: Copyright (c) 2022, TakWolf
- License: SIL Open Font License 1.1; see `OFL-Fusion-Pixel.txt`
- Source asset: `fusion-pixel-font-12px-monospaced-otf.woff2-v2026.08.11.zip`
- Subset purpose: shared WebGL game scores, timers, counters and short status labels

The subset currently contains ASCII letters, digits, score punctuation and the
Simplified Chinese UI vocabulary declared in `src/ui/pixel-text.js`. Expand that
character list and regenerate the subset when a game needs additional glyphs.
